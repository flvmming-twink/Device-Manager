# Device Manager 1.0.1

Версия приложения `1.0.1`, versionCode `3`, пакет `ru.misis.devicemanager`. Отладочный APK для установки и проверки, Android 5.0+.

## Изменения

- Полный редизайн через Impeccable: технический каталог, новая палитра, открытые строки реестра, заметные кабинеты, Material 3, новая иконка.
- QR-код карточки устройства: открытый JSON или гибридное AES-256-GCM + RSA-2048-OAEP.
- Чтение камерой, из изображения и JSON; просмотр данных перед сохранением.
- Сохранение PNG/JSON, создание и перенос ключей организации в файле под паролем.
- Сохранены реестр, редактор, статусы, расположение, фильтры, корзина и CSV.

## Установка

[DeviceManager-v1.0.1-debug.apk](DeviceManager-v1.0.1-debug.apk). Устанавливается обновлением поверх предыдущей сборки Device Manager при совпадении подписи. Данные реестра сохраняются; удалять приложение перед обновлением не нужно. Contact Manager использует другой пакет.

Базовая версия 0.1.0 переименована и пересобрана как [1.0.0](../Device%20Manager%20v1.0.0/README.md), versionCode `2`.

## QR

В меню записи или сохранённой карточке выберите «QR-код». Открытый режим читается любым сканером и содержит все поля. Для защищённого режима создайте или импортируйте ключ организации через «QR-метки и ключи». Передайте коллегам файл ключа под паролем, пароль — отдельно. После удаления приложения для восстановления доступа потребуется этот файл.

Метку нужно выпускать заново после изменения устройства: она содержит снимок карточки. Сканирование не записывает данные автоматически; проверьте результат и сохраните через редактор. При переполнении QR данные не обрезаются — доступен полный JSON-файл.
