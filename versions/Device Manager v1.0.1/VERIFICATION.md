# Проверка Device Manager 1.0.1

Дата: 27 ноября 2026. Отладочный APK, `ru.misis.devicemanager`, versionName `1.0.1`, versionCode `3`. JDK 17, Gradle 8.6, Android SDK 34.

## Автоматические проверки

Команда: `gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleDebug --max-workers=2 --console=plain`.

32 теста, 0 ошибок, 0 пропусков. JUnit XML и полный отчёт lint находятся в `verification/`.

| Набор | Тестов | Сценарии |
| --- | ---: | --- |
| DeviceRulesTest | 8 | Поля, статусы, поиск, фильтры, сортировка, CSV |
| DeviceRepositoryTest | 9 | SQLite, уникальность, сохранение, корзина, восстановление и транзакции |

Lint: 0 ошибок, 72 предупреждения. В основном это унаследованные неиспользуемые ресурсы и доступные обновления библиотек. Предупреждения не скрыты baseline-файлом.

## Нативная проверка

Выделенный эмулятор Pixel 2, Android 9 / API 28, x86_64, 1080 × 1920. Данные МИСИС, INV-001…003 и ключ MISIS-QA синтетические, находятся только в эмуляторе и не включены в APK.

- Установка обновлением сохраняет существующую базу оборудования.
- Открытие реестра и карточки, светлая/тёмная темы и системный шрифт 130%; после сценариев системная тема и масштаб восстановлены.
- Генерация открытого и защищённого QR, сохранение PNG через системный выбор файла.
- Чтение защищённого PNG и JSON, расшифровка полей и определение существующей карточки.
- Создание ключа, экспорт под паролем и обратный импорт на Android.
- Запрос разрешения камеры, открытие сканера напрямую из реестра и возврат назад. Подсказка камеры проверена поверх яркого синтетического изображения. Физическая печатная метка не сканировалась.
- После сборки исправлены сохранение прокрутки и состояния кнопок при открытии, сохранении и отмене системного выбора JSON/PNG. Кнопки остаются доступными, QR-экран остаётся на позиции с действиями экспорта.

Параметры шрифта и системной темы восстановлены после проверки. Во время подготовки снимков произошёл сбой графической подсистемы эмулятора; невалидные снимки заменены после перезапуска.

## Ограничения проверки

Проверены перечисленные телефонные сценарии на API 28. Физический телефон, планшет, TalkBack, вся матрица Android 5.0+ и качество чтения печатных меток в разных условиях не проверялись. Общего сервера и автоматической синхронизации нет. Защищённые метки требуют соответствующего ключа организации.

Независимая проверка Impeccable: полный обзор признал тему и основные рабочие сценарии целостными; не потребовал перестройки. В ограниченном повторном вердикте исправления прокрутки/доступности экспорта и контраста подсказки камеры оценены отдельно. Ограничения визуального сравнения указаны в `verification/finish-review.md`; численный comp-diff — справочный, его пиксельный порог не пройден. Проверены только перечисленные телефонные состояния.
