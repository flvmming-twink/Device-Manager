# Device Manager 1.1.3

Предварительный релиз (`Pre-release`) приложения `ru.misis.devicemanager`, versionCode `7`, Android 5.0+.

## Новые возможности

- **Настройки:** длинное меню заменено отдельным экраном с группировкой экспорта, переноса, инвентаризации, массовых действий, QR, тем и информации о приложении.
- **Экспорт XLSX:** создание книги Excel с текущим отображаемым списком и применёнными фильтрами. Экспорт работает локально через системный выбор места сохранения.
- **CSV сохранён:** прежний экспорт доступен на том же экране настроек.

Формат данных, база SQLite, QR и передача JSON не менялись. Серверной синхронизации нет.
