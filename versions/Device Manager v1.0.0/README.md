# Device Manager v1.0.0

Первая версия для учёта оборудования университета и организаций на основе Contact Manager.

- Карточки оборудования с инвентарным номером, типом и серийным номером.
- Организация, корпус, кабинет, ответственный и примечания.
- Статусы «Действующее» и «На списание» с причиной.
- Поиск, фильтры и сортировка.
- Удаление в корзину, восстановление и окончательное удаление.
- Экспорт отображаемого списка в CSV.
- Локальная SQLite-база, светлая/тёмная/системная темы.

Устанавливается отдельно от Contact Manager: `ru.misis.devicemanager`, версия `1.0.0`, код версии `2`. Данные хранятся на одном устройстве; серверной синхронизации нет.
