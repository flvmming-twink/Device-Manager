# Device Manager 1.1.1

Предварительный релиз (`Pre-release`) приложения `ru.misis.devicemanager`, versionCode `5`, Android 5.0+.

## Исправление передачи

В 1.1.0 прямое Bluetooth-соединение обрывалось на части устройств. В 1.1.1 приложение больше не сканирует устройства и не открывает собственный Bluetooth-сокет. Оно передаёт JSON-файл через системное меню Android; в качестве транспорта пользователь может выбрать Bluetooth, Quick Share или другое доступное рядом приложение. Получатель выбирает уже полученный файл через «Получить данные».

Так Android управляет подключением, сопряжением, повтором и разрешениями выбранного транспортного приложения. Уровень защиты канала зависит от выбранного приложения. Device Manager проверяет целостность файла, показывает карточки и не изменяет локальный реестр до подтверждения.

## Сценарии

1. В меню реестра откройте «Передача данных между устройствами» → «Передать данные».
2. Выберите одну или несколько карточек; «Назад» отменяет выбор.
3. Нажмите «Продолжить», затем выберите в Android Sharesheet Bluetooth, Quick Share или другой способ передачи рядом.
4. На принимающем телефоне сохраните полученный JSON-файл.
5. В Device Manager откройте «Получить данные» → «Выбрать файл передачи».
6. Проверьте предпросмотр и подтвердите импорт. Дубликаты по организации и инвентарному номеру будут пропущены без перезаписи.

За операцию передаётся один JSON-файл до 8 MiB, содержащий до 250 карточек. В файл входят примечания и остальные portable-поля устройства, но не входят локальные ID и сведения о корзине. QR-метки и ключи организации сохранены.
