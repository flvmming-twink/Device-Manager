# Device Manager 1.2.0

Предварительный релиз (`Pre-release`) приложения `ru.misis.devicemanager`, versionCode `8`, Android 7.0+.

## Новые возможности

- Общий реестр устройств с автоматической синхронизацией между телефонами через Firebase Cloud Firestore.
- Создание общей базы на устройстве-источнике и подключение остальных телефонов по случайному коду приглашения.
- Локальная очередь изменений с отправкой при восстановлении сети.
- Отдельные документы карточек вместо экспорта и пересылки большого JSON-файла.

Для включения облачной синхронизации организации нужно создать Firebase проект, включить Anonymous Authentication и Cloud Firestore, добавить `google-services.json` в `app/`, опубликовать правила из `firebase/firestore.rules` и пересобрать APK. Без этой конфигурации приложение работает локально; кнопки облачной синхронизации недоступны. Пошаговая инструкция: [firebase/SETUP.md](../../firebase/SETUP.md).

В общей базе синхронизируются карточки, статусы и корзина. История изменений и инвентаризации помещений остаются локальными. Если две офлайн-правки одной карточки сталкиваются, последняя успешно отправленная карточка заменяет другую без слияния полей.
