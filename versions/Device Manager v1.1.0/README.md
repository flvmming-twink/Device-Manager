# Device Manager 1.1.0

Предварительный релиз (`Pre-release`) приложения `ru.misis.devicemanager`, versionCode `4`, Android 5.0+.

## Что нового

- Ручная передача одной или нескольких карточек оборудования между Android-телефонами по Bluetooth Classic RFCOMM.
- Отправитель выбирает карточки в реестре; кнопка продолжения появляется после выбора.
- Получатель заранее включает приём, просматривает отправленные записи и подтверждает импорт.
- Совпадения по организации и инвентарному номеру пропускаются, локальные данные не перезаписываются.
- Разрешения Bluetooth запрашиваются в контексте операции. Приложение не ищет устройства в фоне.
- QR-коды, включая открытый JSON и защищённые AES-256-GCM + RSA-2048-OAEP, сохранены.

## Как передать

На обоих телефонах откройте меню главного экрана → «Передача данных по Bluetooth».

1. На телефоне получателя нажмите «Получить данные» и примите системный запрос Android на Bluetooth и временную видимость.
2. На телефоне отправителя нажмите «Передать данные», отметьте одну или несколько карточек и выберите «Продолжить».
3. Выберите телефон-получатель. При первом соединении подтвердите сопряжение в системном диалоге Android.
4. На телефоне получателя проверьте список и подтвердите импорт. Совпадения по инвентарным номерам будут пропущены.

Передаются поля карточек, включая статус, местоположение, ответственного и примечания. Локальные ID и сведения о корзине не передаются. За раз можно отправить до 250 записей; максимальный размер пакета — 8 MiB.

Защищённый RFCOMM-сеанс Android использует сопряжение и шифрование Bluetooth-канала. Получателю всё равно необходимо отдельно подтвердить импорт. QR-обмен остаётся доступен для офлайн-обмена.
