Device Manager 1.2.0 — описание фронтенда

Общая база устройств
В экран «Настройки» добавлен пункт «Общая база устройств». Экран показывает состояние подключения, поле для кода базы и кнопку подключения. Если Firebase ещё не подключён к сборке, экран выводит краткое объяснение и открывает пошаговую инструкцию.

Создание общей базы
На устройстве с исходным реестром пользователь нажимает «Создать общую базу». Приложение формирует случайный код доступа, отправляет существующие карточки в облачное хранилище по отдельности и показывает код для копирования или передачи штатным меню Android. Код следует передавать только участникам организации.

Подключение устройств
На другом телефоне пользователь вводит код и нажимает «Подключить это устройство». После подключения карточки общей базы появляются в основном списке. Если локальная карточка совпадает по организации и инвентарному номеру, она связывается с общей записью вместо добавления копии.

Поведение списка и офлайн-режим
Поиск, фильтры, карточки устройств, QR, аудитория и остальные прежние экраны работают так же. Облачные изменения обновляют список при запущенном приложении. При отсутствии сети пользователь продолжает редактировать локальные данные; экран показывает статус подключения, а приложение отправляет очередь изменений после восстановления сети. Если процесс приложения был закрыт, очередь будет отправлена при следующем запуске.

Ограничения интерфейса версии
В общей базе синхронизируются карточки устройств и их состояние, включая корзину. Локальная история изменений и результаты инвентаризации аудитории остаются на исходном телефоне. Одновременные правки одной карточки целиком заменяют предыдущую версию после отправки; отдельные поля не объединяются.

Настройка
Для работы на разных сетях требуется создать собственный проект Firebase, подключить Android package `ru.misis.devicemanager`, включить Anonymous Authentication и Firestore, опубликовать правила доступа и собрать приложение с `app/google-services.json`. Полная инструкция находится в `firebase/SETUP.md`. До добавления этого файла облачные действия недоступны, а локальный реестр продолжает работать.

Совместимость
- versionCode 8, versionName 1.2.0, Android API 24+.
- Основной экран по-прежнему работает локально; интернет и Bluetooth не запрашиваются при запуске.
- Разрешение на доступ к состоянию сети объявлено в манифесте; runtime-разрешение Bluetooth этой функции не требуется.
