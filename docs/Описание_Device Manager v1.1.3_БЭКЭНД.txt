Device Manager 1.1.3 — описание бэкенда

Архитектура
Серверной части нет; устройства и история остаются в локальной SQLite-базе. Изменения схемы БД для этой версии не требуются. Настройки — отдельный Android Activity, который возвращает выбранное действие главному экрану; сами существующие процессы экспорта, QR, передачи, аудита, корзины и массовых изменений продолжают работать в прежних компонентах.

Экспорт книги Excel
DeviceXlsx формирует минимальную книгу Office Open XML непосредственно в ZIP-поток без дополнительной библиотеки. Архив содержит типы содержимого, связи пакета, описание книги и один лист xl/worksheets/sheet1.xml с именем «Оборудование». Ячейки представлены inline strings в UTF-8; XML-спецсимволы экранируются, а пользовательские данные не записываются как формулы. Даты и внутренние локальные ID не экспортируются.

Список для экспорта передаётся из текущего отображаемого списка адаптера после поиска и фильтрации. Документ создаётся через ActivityResultContracts.CreateDocument с MIME application/vnd.openxmlformats-officedocument.spreadsheetml.sheet и записью в фоновом IO-диспетчере. CSV остаётся отдельным экспортом.

Данные и ограничения
В XLSX включены 11 человекочитаемых полей карточки. Экспорт отражает состояние фильтров на момент запуска и не включает записи, скрытые поиском или текущими фильтрами. При пустом отображаемом списке показывается сообщение, файл не предлагается. SQLite, пакет установки ru.misis.devicemanager, перенос JSON, QR-протокол и структура истории не меняются.

Совместимость и сборка
- versionCode 7, versionName 1.1.3, Android API 21+, target SDK 34.
- Дополнительные библиотеки не добавлены.
- Серверная синхронизация и фоновые сетевые операции отсутствуют.
