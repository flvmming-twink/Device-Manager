# Подключение общей базы Device Manager к Firebase

Приложение хранит рабочие данные в локальной SQLite-базе и синхронизирует карточки через Cloud Firestore. Firebase — управляемое облако: отдельный физический сервер организации не нужен. Для работы на телефонах из разных сетей необходим Firebase проект и его конфигурация в APK.

## 1. Создайте Firebase проект

1. Откройте [Firebase Console](https://console.firebase.google.com/) и войдите в Google аккаунт организации.
2. Нажмите **Создать проект**. Введите название, например `MISIS Device Manager`.
3. Google Analytics для этого приложения можно не включать.
4. После создания откройте настройки проекта и нажмите **Добавить приложение → Android**.
5. В поле **Имя пакета Android** укажите точно `ru.misis.devicemanager`. Псевдоним можно оставить пустым; SHA-1 для используемой здесь анонимной аутентификации не требуется.
6. Скачайте `google-services.json`.

## 2. Добавьте конфигурацию в проект и соберите APK

Поместите скачанный файл в `app/google-services.json` в локальной копии проекта. Этот файл специфичен для проекта Firebase и исключён из Git через `.gitignore`, поэтому он не попадёт в открытый репозиторий.

Соберите APK из корня проекта:

```powershell
.\gradlew.bat :app:assembleDebug
```

Готовый APK будет здесь: `app/build/outputs/apk/debug/app-debug.apk`. Установите именно эту сборку на телефоны организации. Файл Google Services добавляется на этапе сборки; одной установки Firebase в консоли недостаточно, чтобы включить облачную функцию уже опубликованного APK.

## 3. Включите вход и Firestore

1. В Firebase Console откройте **Authentication → Sign-in method** и включите **Anonymous**.
2. Откройте **Firestore Database → Create database**. Выберите production mode и регион, подходящий требованиям организации. Выбранный регион базы после создания изменить нельзя.
3. На вкладке **Rules** вставьте содержимое [firestore.rules](firestore.rules) и нажмите **Publish**. Не оставляйте тестовые правила вида `allow read, write: if true`.

## 4. Подключите телефоны

1. На телефоне с исходным списком откройте **Настройки → Общая база устройств → Создать общую базу**.
2. Приложение загрузит карточки как отдельные документы и покажет код. Код можно скопировать или отправить штатным меню Android.
3. На остальных телефонах откройте **Общая база устройств**, введите код и нажмите **Подключить это устройство**.
4. После подключения карточки будут синхронизироваться, пока приложение работает. Изменения без сети остаются в локальной очереди и отправляются при восстановлении сети или следующем запуске приложения.

Код — это приглашение с правом редактировать общий реестр. Любой, кто получил код, может присоединиться и менять карточки. Передавайте код только доверенным сотрудникам. Чтобы ограничить доступ после утечки, создайте новую общую базу и раздайте новый код.

## Что входит в синхронизацию

- Карточки, местоположение, ответственный, статус, корзина и изменения карточек.
- Новая карточка создаётся отдельным документом Firestore; приложение не пересылает большой JSON-экспорт.
- Журнал событий карточек, результаты инвентаризации помещений и настройки остаются локальными на телефоне.
- При одновременной офлайн-правке одного устройства последняя успешно отправленная карточка заменит предыдущую целиком; автоматического слияния отдельных полей нет.
- При совпадении организации и инвентарного номера карточки с другой БД объединяются в одну запись; подключаемая общая запись заменяет локальные поля этой карточки.

## Android и стоимость

Используемые Firebase Authentication 25 и Cloud Firestore требуют Android 7.0 / API 24, поэтому минимальная версия Android в Device Manager 1.2.0 повышена с API 21 до API 24. Актуальные квоты и условия тарифа проверьте на странице [цен Firestore](https://firebase.google.com/docs/firestore/pricing). Платный тариф может требовать привязки платёжного профиля; стоимость зависит от использования, региона и настроек Google Cloud.

Официальная справка: [подключение Firebase к Android](https://firebase.google.com/docs/android/setup), [анонимная аутентификация](https://firebase.google.com/docs/auth/android/anonymous-auth), [правила Firestore](https://firebase.google.com/docs/firestore/security/rules-conditions), [офлайн-режим Firestore](https://firebase.google.com/docs/firestore/manage-data/enable-offline).
